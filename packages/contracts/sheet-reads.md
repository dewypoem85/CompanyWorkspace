# 시트 조회 계약과 본문 수명주기

`api.ts`는 동일 출처 인증/no-store/JSON과 원래 HTTP 상태를 보존하고 `sheetReads.ts`의 전체 응답 검증을 통과한 데이터만 반환한다. 로그인 HTML, 손상 JSON, 잘못된 날짜/건수/열 구조/중복 ID/다른 행 대상은 렌더링하지 않는다. 링크는 사용자정보 없는 HTTP(S)만 허용한다. 셀 문자열은 숫자로 바꾸지 않으며 원래 Google 숫자 셀의 number 의미는 유지한다.

- 설정: mode, writesEnabled, 현재 회사 actor 문자열 ID, 기본 문서 ID/URL. actor는 쓰기 요청의 계정 결합에 사용하지만 영구 revision이나 인증 토큰은 아니다.
- 분석: 문서·시트·규칙 전체 필드와 ready/blocked 합계를 검증한다. 공개 API의 규칙 목록은 최대 150개이고 총계는 전체 문서 기준이므로 두 개수를 같다고 요구하지 않는다. 파싱 실패로 blocked인 원문의 빈 위치도 기존 계약으로 수용한다.
- 한국어 비교: Korean 언어, 문서/규칙 대상, 원본 링크/값, tracked/changed/unchanged와 실제 전체 행 수를 대조한다. UI의 최대 300행 표시는 응답 검증 뒤 적용한다.
- 스냅샷: 전체 목록 메타데이터의 ID·작업 종류·시각·대상·분석 ID·셀 수를 검증한다. 서로 다른 문서의 기록도 허용하며 셀 원문/복원은 이 조회에 포함하지 않는다.

`useSheetData`가 초기 설정/분석/스냅샷, 재분석, 한국어 비교의 본문 상태를 소유한다. 초기 세 응답은 모두 성공해야 표시하고 일반 재조회 실패에는 마지막 정상 결과와 공통 error 안내를 유지한다. 분석의 기본 문서 ID/모드, 비교 대상 ID를 현재 설정과 대조한다. 생성된 `createWorkspaceReadSession`의 `WorkspaceReadSession`과 `main`·`preview` 채널이 교체·취소·30초 관찰 제한과 최신 ticket 판정을 소유하며, 로컬 owner는 오래된 finally가 현재 로딩 상태만 풀지 못하게 한다. 취소를 무시하는 fetch/JSON 이후에도 오래된 결과를 적용하지 않고 실패한 병렬 읽기의 남은 요청도 관찰을 취소한다.

비교 도중 다른 화면으로 가면 그 요청만 취소한다. 이미 검증한 비교값은 돌아왔을 때 보존되지만 재분석/저장 후 갱신 성공 시 과거 비교는 폐기한다. 현재 분석 중에는 새 비교를 시작하지 않는다. 명시적 재시도는 기존 분석/비교 POST와 목록 GET만 사용하며 실제 시트 쓰기 API를 재전송하지 않는다. 이 POST는 서버에 분석/규칙 기록을 남길 수 있으므로 GET이나 모든 부작용이 없는 요청으로 설명하지 않는다.

401/403의 `sheet-access-denied`, 회사 공통 계정 범위 변경 또는 non-persisted pagehide에서는 설정·분석·비교·스냅샷과 원본 링크를 제거한다. 공통 denied 안내와 명시적인 문서 다시 열기만 제공하며 이전 본문에서 재조회/후속 저장 결과로 되살리지 않는다. 저장 확인과 후속 읽기도 동일 무효화 신호를 소비한다. bfcache 보관은 연결을 유지하고 React 해제/StrictMode 재연결은 이전 요청만 취소한다. 프로필 사진만 바뀐 경우는 공통 scope-change가 아니므로 재로그인을 요구하지 않는다.

현재 한계: 기존 서버 SSO/쓰기 설정/충돌/스냅샷 정책은 그대로다. 이 클라이언트 범위 검사는 요청마다 서버에 expected actor/revision을 보내 대조하는 계약을 추가하지 않는다. 공통 계정 이벤트가 오기 전의 서버 계정 변경을 모든 읽기에서 검출한다고 주장하지 않는다. `useSheetActions`의 POST와 성공 후 묶음 조회는 `sheet-writes.md`의 공통 쓰기/read session을 사용하지만 서로 다른 hook 간 채널은 독립적이다. 실행 abort/timeout은 서버 롤백 보장이 아니며 운영 반영은 별도다.

검증: 시트 타입 검사·단위 테스트, 실제 배포 번들/격리 서버와 `sheet-shell.spec.mjs`의 PC/모바일·두 테마/기존 쓰기 확인·재조회/손상 응답/대상 변경/권한 거부·계정 변경 뒤 늦은 JSON/비교 중 화면 이동을 검사한다. 실제 운영 Google 호출 대신 합성 HTTP만 사용한다.
