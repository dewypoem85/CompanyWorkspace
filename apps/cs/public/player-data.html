PlayFab player data

플레이어 데이터

UID의 플레이어 데이터, 읽기 전용 데이터, 내부 데이터를 조회하고 편집합니다. UserData의 압축된 SaveData는 자동으로 풀어서 보여줍니다.

세 가지 데이터 저장소

UserData, UserReadOnlyData, UserInternalData의 모든 키를 저장소별로 관리합니다.

동시 편집 보호

저장 직전에 PlayFab 값을 다시 확인하며 달라졌다면 저장을 중단합니다.

SaveData 압축

gzip-v1:{원본바이트수}:{Base64}를 검증·해제하고 저장 시 압축 키로 전환합니다.
