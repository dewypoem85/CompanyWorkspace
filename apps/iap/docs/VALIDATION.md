- 브라우저에서 기존 포털 로그인이 유지되고, IAP 권한 없는 테스트 계정의 상품 관리 진입이 접근 거부되는 것 확인. 권한 있는 계정의 SSO 완료·프로젝트 연결·인증 후 기능 검증은 아직 미완료.
